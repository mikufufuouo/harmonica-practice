## 项目是什么

个人口琴练习 PWA，local-first，无账号/后端。当前入口是私人曲谱库，图片原谱与 BD 结构化谱共存；音频线仍处于单音采样实验，不做识别或评分。用户的 12 孔琴为孔声 KB-12 C 调，具体是否标准 Solo 音位仍待实物核对，不能套用 10 孔 Richter 指法。

歌曲音符层仍为 NoteSequence，BD 是来源与派生指法。新谱首版由 Agent 找并核对旋律谱，生成可审查 JSON 再在 PWA 产出 12 孔 BD；图片 OCR 暂为后续入口。契约：[转谱](SCORE_TO_BD.md)、[图片谱](IMAGE_SCORES.md)、[音符](NOTE_SEQUENCE.md)、[转录/OCR](IMAGE_IMPORT.md)。

## 当前问题 / 下一包

- 用户点名一首歌后，Agent 查找可核对的单旋律谱，记录来源、调号/八度/时值/声部与推断，生成 NoteSequence JSON，在 PWA 对照原谱→音符→BD 完成一首真实歌的人工验收；当前没有指定歌名。先用用户 KB-12 核对 1B=C4、1D=D4 和标准/Orchestral 版本，确认后才能把暂定指法称为个人琴映射。
- 图片识谱若成为下一入口，先拿真实简谱样本验证 jpeditor 等本地 OMR 的版式适应性和校对耗时；通用文字 OCR 不可靠识别八度点/时值线。10 孔 bend/overblow、易吹版与自动选调另阶段设计，不把理论可达音等同易吹。
- 旧图片谱实机门槛仍待：用户手机/iPad 用私人 ZIP 验证长图手势、横竖屏、全屏、离线重开和备份；记录设备/系统/浏览器/版本/现象，出现大包内存问题再按证据优化。
- 图片谱备份包含原图，但关联的 BD 内容仍需单独 JSON 备份；单包上限 750 MiB，处理时会占内存。清理站点数据会丢本机谱库；不同浏览器/域名/设备不会自动同步。
- 后续新增购买：Agent 按 [图片谱说明](IMAGE_SCORES.md) 重新从用户登录页面收集当次授权索引，运行整理工具，再批量导入更新。无需用户逐首整理；登录/权限不明时才请用户处理。
- 不因图片看谱成功就进入 OCR/跟练/评分。OCR 原路线保留待验证；音频线仍需真实试样，见 [EXPERIMENT](EXPERIMENT.md)。
- SW 更新不强制刷新，在线访问后关闭所有该站/PWA窗口再重开；先核对脚本版本再判断部署问题。
