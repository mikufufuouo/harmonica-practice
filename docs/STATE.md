# 当前状态与下一步

更新：2026-09-14。应用代码基线：`85731e7`，本轮从干净的 `132a948` 接续。此页覆盖更新，历史看 Git。

## 项目是什么

个人 10 孔口琴练习 PWA，面向能看 BD 吹旋律、但难确认单孔的初学者。横屏优先，以真实孔位与 B/D 交互，最终提供跟练和有依据的训练建议。核心未证实问题是如何区分单孔泛音与相邻多孔，不能用命中主音代替纯净判断。

实际主要谱源是公众号 BD + 歌词图片。歌曲底层为与乐器无关的 NoteSequence，BD 是导入格式与派生指法；图片先人工确认再进本地曲库。具体原因见 [DECISIONS](DECISIONS.md)。

## 已交付与尚未实现

- 音频 0A：虚拟口琴意图选择、麦克风 PCM、最多 5 秒采样、取消/回放、WAV + 元数据主动导出。音频仅内存；没有 pitch detection 或串孔识别。
- 谱面 S0：统一歌曲 schema/运行时校验、严格 BD 自然音文本解析、独立未对齐歌词行、原曲 JSON 导出；C/G/A/D/F/Bb 标准 Richter 自然音指法、同音候选、显式移调且不改原曲。
- 图片与谱库：单图本地保存/回看；Tesseract.js 英文或中英模型按需 OCR；原文与编辑行分开，BD/歌词/忽略行人工分类，逐行及整图确认，改动使确认失效；草稿选择/删除/刷新恢复，确认后存 IndexedDB 谱库，指法与歌词查看、单曲/谱库 JSON 导入导出、删除及无引用原图清理。JSON 不含原图或完整草稿。
- PWA：安装清单/图标、离线外壳、相对子路径、公开 GitHub Pages 持续部署。无账号/后端。
- 未实现：应用内裁剪/逐 token 坐标、长图自动分区去重、候选纠错/置信度、完整 revision 审核历史、含原图备份、自动歌词对齐、其他格式解析器、跟练、演奏报告和能力画像。S1 手机门槛和 S2 真实截图指标尚未通过。
- 技术栈：Vite + TypeScript 原生 DOM，AudioWorklet 采集，Tesseract.js 7 Worker OCR。依赖及命令以 package.json/lock 为准。

## 当前问题 / 未知

- 用户琴调、型号/是否标准 Richter、主要手机与浏览器未知；界面默认值不能替代用户确认。
- 真机需验证录制→回放→导出、横竖屏、安装/离线及后台中断。采集以 2048 样本批次传递，开始/结束含调度偏差，不能用它直接测精确起音延迟。
- BD 解析仅支持已列出的自然音语法；复杂混排、压音/延音等会报错，不能宣称兼容所有公众号。
- OCR 当前是试验入口，先在相册裁剪清晰短图；准确率、漏行率、人工修正收益和手机耗时未验收。首次下载依赖 CDN；清理浏览器站点数据会丢本地谱库/图片，歌曲可主动 JSON 备份。
- SW 不强制刷新，更新需在线访问后关闭所有该站点/PWA 窗口再重开。排查旧页面先确认版本与等待中的更新，勿直接归因部署失败。

- 无真实图时可继续自造边界测试，但不能宣称公众号兼容性；不提前接整首评分。专题契约与指标见 [IMAGE_IMPORT](IMAGE_IMPORT.md)。
