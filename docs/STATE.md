## 项目是什么

个人口琴练习 PWA，local-first，无账号/后端。当前入口是私人曲谱库，图片原谱与 BD 结构化谱共存；音频线仍处于单音采样实验，不做识别或评分。用户现有半音阶口琴谱用于原图看谱，不能套用 10 孔 Richter 指法。

歌曲音符层仍为 NoteSequence，BD 是来源与派生指法。图片资源无需音符或 OCR；要转成音符时仍需人工确认。契约：[图片谱](IMAGE_SCORES.md)、[音符](NOTE_SEQUENCE.md)、[转录/OCR](IMAGE_IMPORT.md)。

## 当前问题 / 下一包

- 先在用户主要手机/iPad，用已整理 ZIP 一次导入，验证长图手势、横竖屏、全屏、离线重开和备份。记录设备/系统/浏览器/版本/现象；若大包触发内存问题，再按证据做流式解包或分包。
- 图片谱备份包含原图，但关联的 BD 内容仍需单独 JSON 备份；单包上限 750 MiB，处理时会占内存。清理站点数据会丢本机谱库；不同浏览器/域名/设备不会自动同步。
- 后续新增购买：Agent 按 [图片谱说明](IMAGE_SCORES.md) 重新从用户登录页面收集当次授权索引，运行整理工具，再批量导入更新。无需用户逐首整理；登录/权限不明时才请用户处理。
- 不因图片看谱成功就进入 OCR/跟练/评分。OCR 原路线保留待验证；音频线仍需真实试样，见 [EXPERIMENT](EXPERIMENT.md)。
- SW 更新不强制刷新，在线访问后关闭所有该站/PWA窗口再重开；先核对脚本版本再判断部署问题。
