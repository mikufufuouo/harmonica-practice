# 阶段 0：串孔识别实验与验收

本文件中的数字是预先提出的研发门槛，不是已达到的性能。当前没有真实口琴验证数据。

## 先采什么

先用确认调性的标准 Richter，在主要设备上采集 4–6 孔 B/D 的自然音。先做十余段小样本检查采集链路，之后补齐对照，避免一次要求用户录完所有孔。

每段约 2–3 秒，头尾留短静音，目标持音约 1–2 秒；距离、音量保持舒适一致。不要为了产生样本而猛吹。每次采样先标“想吹什么”，录后可标不确定。初学者的“我只吹一个孔”不可直接作为单孔真值。

正式起始矩阵：6 个单孔状态（4/5/6 各 B/D）；4 个相邻双孔（4+5、5+6 各 B/D）；2 个三孔（4+5+6 各 B/D）。每种 5 段独立吹奏、轻/正常两档、两个独立采样会话，共 240 段短音，分多次完成。另录环境、气声、说话、起音不稳和明显削波等负例至少 20 段。近/远距离及第二设备作为后续泛化集，不与第一轮混在一起调参。

先以明显多孔检出建立最低可行性，再采集弱邻孔泄漏；需要报告左/右邻孔、双/三孔及各音区差异。扩到 1–10 孔前另补低音、高音、2D/3B 同音、跨八度、压音、故意颤音等边界例。第一阶段不声称覆盖所有调性与音区。

## 真值与防止自证

保留三层：用户意图、用户听感确认、独立复核。复核需试听与时频证据结合；最好有能稳定吹单孔者的参照，或在不损伤琴且可确认发声通道的控制条件下采集。若无法独立确认，标为 unknown，不拿它证明准确率；也不能用待测算法输出反过来标训练数据。

弱邻孔的“物理声压比例”在实吹时未知。可将经复核单孔做 -6/-12/-18/-24 dB 数字混合来绘制算法敏感度，但这些仅是压力测试，不可替代真实混吹。真实和弦可能不等于单音线性相加。

至少按会话分开训练/校准与最终测试。同一录音切片、同源合成混音不能跨集合。若只有两次会话，一次开发、一次冻结测试；测试后改阈值则原测试集降为验证集，另录新测试会话。

## 评估口径

以独立吹奏事件为主，稳态帧为辅，报告实际样本数量及置信区间（可用按事件/会话重采样）。不能把相邻音频帧当独立样本抬高可信度。

- 单孔误报率：真单孔事件中被报为串孔的比例，门槛 ≤5%。
- 明显串孔召回率：经复核的明显双/三孔事件中正确报串孔的比例，门槛 ≥85%；不确定和漏检都算未检出。
- 可判定覆盖率：符合输入质量要求的全部已复核事件中，给出 single-like 或 suspected-multiple 的比例，门槛 ≥80%；同时报告被质量过滤掉的全部比例，禁止通过拒判所有难例刷分。
- 孔集合：另报候选集合的 precision/recall 和邻孔方向正确率；不能仅有“多音存在”就声称孔位准确。
- 延迟：从音频中可标注的稳定发声开始到屏幕稳定状态，主要设备 p95 目标 ≤250 ms；记录算法时间窗、确认等待、队列、渲染及硬件端到端测法，不能只用 FFT 耗时当实时延迟。
- 持续性：主要设备连续运行 10 分钟，无持续积压、麦克风失控或明显卡顿；中断后状态正确。

先报告指标点估计、分组样本数和区间，不将少量样本的达标当作产品级保证。弱漏音单列曲线，不因未达到明显串孔门槛就修改“明显”的定义。最终需要用户在实际练习中判断反馈是否帮助调整。

## 决策分支

1. B 达标且 C 无明显收益：保留简单、无需校准的 B。
2. C 显著改善：提供短校准流程，但使用复核模板，避免用户串孔样本污染模板。
3. 强串孔可检、弱串孔困难：第一版只提示有明确证据的串孔；其他显示不确定，不销售“纯净度精确评分”。
4. 单孔误报仍高：限制到主要设备/4–6 孔/目标持音，研究质量检测与模型；暂缓整首分析。
5. 真实数据始终不能支持有价值的反馈：调整为 BD 跟练 + 录音自听/对比，不伪造串孔能力。
