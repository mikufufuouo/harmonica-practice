## 审查重点

本轮交付是采样工具，不是识别器。首轮审查要求：

- 权限等待可取消；迟到的 getUserMedia 结果必须立即停止，不能覆盖新的会话。
- 初始化失败释放已取得的麦克风；音频挂起、轨道结束、页面隐藏/离开须中止采样。
- 录音开始冻结意图、调性与实际设置；导出包含版本、会话/采样 id，WAV 与 JSON 能配对。
- 时长取样本数；五秒硬上限、提前完成、取消必须明确区分。
- 回放与采集互斥，Object URL 可释放；界面不渲染每个 128-sample 回调。
- 常见 G/A/B♭ 琴的标准音区不能按 C 调向上转到错误八度。
- 标签始终为用户自报，不自动称为已确认单孔；虚拟琴标明“目标/意图”。
